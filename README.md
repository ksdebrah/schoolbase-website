# SchoolBase website

The public website for SchoolBase, school management for basic schools in Ghana.

- One self-contained page: `index.html`, with `fonts/` (Bricolage Grotesque, OFL) and `img/` (product screenshots from made-up demo schools, and photos from Unsplash under the Unsplash License, credited on the page).
- Served by GitHub Pages from the `main` branch.
- Contact numbers go in the `CONTACT` object near the end of `index.html`.
- "Sign in" links go to the SchoolBase portal.
